How do I use this in my project?

Use the download as your Tailwind v4 entry stylesheet. In an existing entry, keep one @import "tailwindcss"; at the top, then add the remaining generated blocks. Merge any existing dark-variant definition instead of duplicating it.

Try bg-background text-foreground on your page and bg-primary text-primary-foreground rounded-card on a button. Toggle the dark class on <html> to switch modes.

These are text-contrast checks, not a full accessibility certification. See the README for recipes and limitations.
